Codex (Кодекс) — The Hub Discord Activity

Privacy Policy

Last Updated: November 26, 2026

1. Introduction

This Privacy Policy explains how Codex (Кодекс) — The Hub Discord Activity (“Codex”) collects, uses, stores, and protects information when you participate in events or open the Activity inside the The Hub («Хаб») Discord server (Guild ID: 290599464886992896).

2. Data We Collect

We process only the minimum data required to run the community progression system:

  • Discord Account Information (received through the Discord Embedded App SDK / OAuth2 and server events): Discord User ID, username, display name / server nickname, avatar URL, and relevant server role states on The Hub (such as faction role, Server Booster, Patron, or Server Tag).
  • In-Game & Community Activity Statistics on The Hub: voice channel participation duration, selected faction, unlocked achievements and progression tiers, Faction Points (Очки Фракции / ОФ), Crystal Shards (Осколки), Ebony Tickets, Lavka shop items and cosmetic roles inventory, showcase configuration, community reputation score, and referral links (members invited to The Hub).
  • Optional Companion Data: if you voluntarily link a Telegram account or submit a feedback ticket / custom profile image URL, those identifiers and submissions are stored to sync your profile across interfaces (Telegram IDs are cryptographically hashed in static public snapshots).

3. How We Use Your Data

Collected data is used exclusively to operate gameplay features inside Codex and The Hub community server:

  • Rendering your unified profile, achievement cards, showcase, faction leaderboards, and seasonal progress;
  • Calculating rewards (Faction Points, Crystal Shards, Ebony Tickets), referral bonuses, and reward shop (Lavka) inventory;
  • Delivering community moderation tickets, reputation votes, and waitlist notifications requested by you.

4. Storage, Sharing & Zero Advertising Sale

All Activity data is stored in an isolated application database hosted for The Hub Discord server. We do not sell your personal or Discord data, and we never share or transfer it to third parties for advertising, profiling, or marketing purposes. Technical communication occurs only with Discord (and Telegram if you explicitly connect the companion bot) as necessary to provide the Activity.

5. Data Retention & Deletion Requests

  • Automatic Departure Cleanup: if a member leaves The Hub Discord server and remains absent for more than seven (7) consecutive days, their Activity profile, achievements, currency balances, and shop inventory are automatically purged.
  • User Deletion Requests: you may request deletion of your stored profile and statistics at any time by contacting The Hub server administration directly in Discord (Server Owner / Admin Discord ID: 290588183006150657, server administrator channels, or the in-app Feedback Ticket tool). Verified requests are processed promptly.

6. Policy Updates & Terms

We may update this Privacy Policy when new features are introduced to Codex; the “Last Updated” date above reflects the latest revision. Please also review our Terms of Service.

Политика конфиденциальности (Privacy Policy)

Дата последнего обновления: 26 ноября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает порядок сбора, использования, хранения и удаления данных в приложении Codex (Кодекс) — The Hub Discord Activity для участников Discord-сервера The Hub («Хаб») (ID сервера: 290599464886992896).

2. Какие данные собираются

  • Данные учётной записи Discord (через Discord Embedded App SDK / OAuth2 и события бота): Discord User ID, имя пользователя (username) и отображаемый никнейм, ссылка на аватар, а также статусы ролей на сервере The Hub (фракция, Бустер, Патрон, тег сервера).
  • Внутриигровая статистика на сервере The Hub: время в голосовых каналах, выбранная фракция, открытые достижения и их уровни, Очки Фракции (ОФ), Осколки кристаллов, Эбеновые билеты, покупки и роли из Лавки, оформление витрины, репутация и реферальные связи (приглашённые участники на сервере).
  • Дополнительные добровольные данные: идентификатор Telegram при добровольной привязке (в публичном снимке хранится в виде криптографического хэша) и обращения в поддержку (тикеты).

3. Зачем используются данные

Данные используются исключительно для работы вашего игрового профиля, расчёта и отображения достижений, наград, рейтинга фракций, Лавки и сезонных событий внутри Discord Activity.

4. Хранение и передача третьим лицам

Данные хранятся на выделенном сервере проекта «Кодекс». Мы не продаём ваши данные и не передаём их третьим лицам для рекламы, таргетинга или сторонней аналитики.

5. Сроки хранения и удаление данных

  • Автоматическая очистка: при отсутствии участника на сервере The Hub более 7 дней его профиль, достижения, валюты и инвентарь автоматически удаляются.
  • Удаление по запросу: вы можете в любой момент запросить удаление своей статистики и профиля, обратившись к администрации сервера The Hub в Discord (ID владельца / администратора: 290588183006150657 или через тикет обратной связи в приложении).
